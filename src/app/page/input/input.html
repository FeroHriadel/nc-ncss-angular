How to use

There is no component to import. Native input and textarea elements are styled by ncss.css directly, so everything the browser gives you (forms, validation, autofill, mobile keyboards, ngModel) keeps working. In the light theme the field has a slight gray background to set it apart from the page.

Accessibility

  • Give every input a label: a label with for, or aria-label when there is no visible text. A placeholder is not a label.
  • Link hints and errors with aria-describedby, and set aria-invalid="true" on invalid fields. Invalid inputs also get the red border, after the user has interacted with them (native :user-invalid).
  • Use the right type and autocomplete so browsers, password managers and mobile keyboards can help.
  • Disabled inputs are dimmed and leave the tab order. Use readonly if the value should still be focusable and readable.
  • The focus ring shows for keyboard focus only, and the border never carries state alone: invalid also needs the error text.

How to modify it

Every color, size and shadow comes from an --input-* variable defined in :root in ncss.css, and every theme overrides them. Change a variable and every input follows, or set it on a parent element to change only the inputs inside it.
