Sorting

Clicking a header cycles ascending, descending, unsorted. Numbers and strings that hold numbers are compared as numbers, so 1, 2, 10, 13, 101 stay in that order (try the Ticket column, which holds strings). Other text compares naturally ("Item 2" comes before "Item 10"). Numbers come before text, and null, undefined and NaN always come last. Sorting uses the raw data, not what render shows.

Changing what cells show

Give a column a render function, or the table a cellModifier for all other columns. It receives the raw value, the row and the column key.

{{ renderCode }}

HTML cells go through Angular's sanitizer, which removes scripts and event handlers. Add trustHtml only for HTML you wrote. An HTML string cannot contain Angular components: <nc-tree> inside a string would not work. Use asTree(value) or type: 'tree' instead.

Cells with your own template

When a cell needs buttons, links, components or pipes, return asTemplate(templateRef) from render. The template is normal Angular, so (click) and your component's methods work. It receives $implicit (the cell's value), row (the whole row) and key (the column key); a second argument, asTemplate(templateRef, extra), adds more variables. Read the template with viewChild inside render (as below), so the table updates once the template exists. Template cells have no text, so double-click does not copy them and filters see the raw value of the column. Row heights are measured, so tall templates work with virtualized too.

Resizing and reordering

Drag the line at the right edge of a header to resize (it respects minWidth and maxWidth), or focus it and use Left/Right arrows (Shift for bigger steps). Double-click it or press Escape to give the width back to the table. Drag a header onto another one to reorder, or press Alt+Left/Right on a focused header. Both write to columns.

Controls

The bar above the table shows the number of rows on the left and three buttons on the right. Reload puts columns (order, widths, visibility) and sort back as they were when the table was created and emits (reload), where you fetch new data (set loading meanwhile). Columns opens a list with a tick on the shown columns; the choice is written to hiddenColumns. Filter opens the filter dialog (see below). The bar is as wide as the table. When the space is too small it scrolls sideways by dragging or swiping instead of wrapping. It is also available alone as nc-table-controls, and [controls]="false" hides it.

Filtering

The Filter button opens a dialog. Each row is a condition: choose a column, then an operator (the list depends on the column: it only offers "is greater than" when the column holds numbers), then type a value. When a row is complete, the + AND / OR button under it adds the next row. The x at the end of a row removes it (the first row is only cleared). Apply shows the matching rows and the conditions as pills above the table, Clear empties the dialog (press Apply to show all rows again). Closing the dialog or pressing Esc throws the changes away. Click the x on a pill to remove that condition.

  • AND binds tighter than OR: A AND B OR C means (A AND B) OR C.
  • Rows that are not complete (no column, operator or value) are ignored when applying.
  • Text is compared as it is shown: after render / cellModifier. For HTML cells that is the text of the HTML, so contains "chess" finds <b>chess</b> and the tags themselves cannot be searched. Objects and arrays are searched as their JSON text. Numbers always compare by the raw value.
  • Columns that are hidden can still be filtered, and the filter keeps working when you hide them.
  • The row count in the controls reads "x of y rows" while a filter hides rows.

Copying

Double-clicking a cell copies its text. For HTML cells that is the text of the HTML, for trees the JSON.

The tree

nc-tree shows an object or array as a small button. It opens a floating panel where nested objects have a triangle that expands them. The panel does not make the table cell bigger and is not clipped by the table. It closes with Esc, a click outside or scrolling.

Accessibility

  • Roles table, rowgroup, row, columnheader and cell, with row and column counts and indexes, so screen readers announce it as a table.
  • Sortable headers are real buttons and the header has aria-sort. Changes of sort, order and copying are announced in a status region.
  • Resize handles are focusable separators with arrow key support. Reordering has the Alt+Arrow keyboard alternative to dragging.
  • The filter dialog is a modal dialog. Its rows are groups with labelled selects and an input, every button has a title and an accessible name, and the applied filters are a labelled list of pills.
  • The controls are buttons with a title and an accessible name, the row count is a status region, and the column list is a multi-select listbox.
  • Truncated text shows in full as a tooltip.
  • Double-click copy has no keyboard equivalent yet. Text can still be selected and copied normally.
  • The status messages for sort and reorder, and the operator names of the filter, are in English for now (the other filter texts are inputs of nc-table-filter).
