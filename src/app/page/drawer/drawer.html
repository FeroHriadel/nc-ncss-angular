How to use

nc-sidedrawer is a dialog attached to a screen edge. It opens and closes through [(open)], or through the methods show(), hide() and toggle(). It has no trigger of its own: use a normal button. It behaves like the modal, so see the modal page for details.

Accessibility

  • The drawer is role="dialog" with aria-modal="true", named by its heading. Give an ariaLabel if there is no heading.
  • While it is open, the rest of the page is inert and does not scroll.
  • Focus moves inside when it opens and goes back to the button that opened it when it closes. Tab and Shift+Tab stay inside.
  • Escape closes the top-most dialog only. Only a click that starts and ends on the backdrop closes it.
  • Animations stop with reduced motion, and Windows high contrast mode draws borders.
