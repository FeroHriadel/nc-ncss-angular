How to use

nc-crud-list shows rows with a header, a plus button, and edit and delete buttons on every row. It never changes your data: it emits events and you update your own signal. There is nothing else to learn.

Accessibility

  • It is a real ul. Every button has a name that includes the row, such as "Delete, Ship it".
  • With clickable the text is a button: Tab, Enter and Space work and the focus ring follows the theme.
  • Hover and stripe colors reuse the table variables, so contrast is the same as in the table.

How to modify it

Colors and sizes come from --list-* variables defined in :root in ncss.css. They default to the table variables, so every theme works out of the box.
