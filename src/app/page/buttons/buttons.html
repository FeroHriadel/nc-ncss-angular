How to use

The button is an Angular component that sits on a native button element, using the attribute selector nc-button. Because the real element stays in the DOM, type, disabled, aria-* and click events all work as usual.

Class and style

Add your own class and [style] like on any element. Classes are merged with the button's classes. A class only overrides a button style if its CSS comes later or is more specific. Styles in [style] are inline, so they always win.

{{ classStyleCode }}

How to modify it

Every color, size and spacing comes from a --button-* variable defined in :root in ncss.css. Change a variable and every button follows. You can also set a variable on a parent element to change only the buttons inside it.

Behavior

  • Long labels stay on one line and are cut off with an ellipsis. The button never grows wider than its container.
  • Keyboard focus shows a ring from --button-focus-box-shadow (only for keyboard focus, not mouse clicks).
  • Pressing a button scales it to 98%.
  • The outline variant reuses --button-ghost-hover-bg for its hover color.

Plain CSS classes

The component only toggles CSS classes, so you can use them without it. Note that plain markup has no label wrapper, so long text is clipped without an ellipsis.
