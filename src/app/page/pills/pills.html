Class and style

Add your own class and [style] like on any element. Classes are merged with the pill's classes. A class only overrides a pill style if its CSS comes later or is more specific. Styles in [style] are inline, so they always win.

{{ classStyleCode }}

Accessibility

  • The remove button is a real button with a name made of closeLabel and the pill's text ("Remove, Angular"), so each one is distinguishable.
  • The pill itself is static text. Put a group of pills in a ul with a label, as in the example, so screen readers announce "list, 4 items".
  • When a pill is removed the focus would be lost. Move it to a neighbouring remove button (as the example does) and announce the change in a role="status" element.
  • The remove button has a visible keyboard focus ring and a hover state, and meaning never depends on color alone.
  • Windows high contrast mode draws a border around pills, and reduced motion turns off the transition.

How to modify it

Every color and size comes from a --pill-* variable defined in :root in ncss.css, and every theme overrides them. The dark, red and outline variants reuse the button variables. Change a variable and every pill follows, or set it on a parent element to change only the pills inside it.
