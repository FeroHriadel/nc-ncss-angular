How to use

nc-collapsible is a show/hide section. The trigger text goes in slot="trigger", the rest is the content. The trigger is a button, so do not put links or buttons inside it. It opens and closes through [(open)] or show(), hide() and toggle().

Accessibility

  • The collapsible is a button with aria-expanded and a labelled region. Closed content is inert, so Tab skips it and screen readers do not read it.
  • Animations stop with reduced motion.
