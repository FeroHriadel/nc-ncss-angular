Class and style

Add your own class and [style] like on any element. Classes are merged with the card's classes. A class only overrides a card style if its CSS comes later or is more specific. Styles in [style] are inline, so they always win.

{{ classStyleCode }}

How to modify it

Colors and spacing come from --card-* variables defined in :root in ncss.css. Change a variable and every card follows, or set it on a parent element to change only the cards inside it.
