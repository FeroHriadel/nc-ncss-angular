How to use

The switch is an Angular component with the element selector nc-switch. Inside it is a real input type="checkbox" with role="switch", wrapped in a label and drawn with CSS. Use it for settings that take effect immediately (on/off). For choices that are submitted with a form, use a checkbox.

Accessibility

  • It is a native checkbox with role="switch", so Space toggles it, Tab moves to it, and screen readers announce "switch" with its on/off state.
  • The visible label is the accessible name, and clicking it toggles the switch. Use ariaLabel only when there is no visible label.
  • ariaDescribedby links a hint, so it is read together with the switch.
  • State is never shown by color alone: the knob also moves from one side to the other.
  • The knob is CSS only, so it is never read out. Disabled switches leave the tab order.
  • Related switches should sit in a fieldset with a legend.
  • The focus ring shows for keyboard focus only. Windows high contrast mode uses system colors, and reduced motion turns off the transitions.

How to modify it

Every color, size and shadow comes from a --switch-* variable defined in :root in ncss.css, and every theme overrides them. Change a variable and every switch follows, or set it on a parent element to change only the switches inside it.
