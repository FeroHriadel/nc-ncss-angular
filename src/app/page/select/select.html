How to use

The select is an Angular component with the element selector nc-select. Give it a list of {{ '{ value, label }' }} options. It supports single and multiple selection, search, keyboard navigation (arrows, Enter, Space, Escape) and always stays on screen: the list opens upward, shifts sideways or scrolls when there is no room.

Native select

A plain select element is styled by ncss.css too, with the same --select-* variables, so it matches nc-select in every theme. Only the closed control is styled. The option list is drawn by the browser and can't be themed. Use it when you want native behavior (forms, mobile pickers).

How to modify it

Every color, size and shadow comes from a --select-* variable defined in :root in ncss.css, and every theme overrides them. Change a variable and every select follows, or set it on a parent element to change only the selects inside it.

Behavior

  • Single select closes after a pick. Multiple select stays open and toggles options.
  • Keyboard: Enter, Space or the arrow keys open it. Arrows move the highlight, Enter or Space picks, Escape closes.
  • The list never leaves the screen: it opens upward when there is no room below, shifts sideways away from the screen edge, and scrolls when it is taller than the space available.
  • Long labels are cut off with an ellipsis. The list scrolls after 6 options.
  • With multiple, the trigger shows the label for one pick and "N selected" for more.
