How to use

The container is an Angular component with the element selector nc-container. It centers its content and limits its width to 1200px, with side padding that shrinks on very narrow screens. Use it to keep page content readable on wide monitors.

It has no inputs. It is a block element, so it takes the full width up to its maximum.

Class, style and attributes

Add your own class, [style], id or any other attribute to nc-container like on any element. Styles in [style] are inline, so they always win.

{{ classStyleCode }}

Accessibility

  • The container is purely visual and has no role, so screen readers ignore it and read its content as usual.
  • Give the page real landmarks: wrap the container in main, header, nav or footer, or set a role on the container itself.
  • The side padding keeps text from touching the screen edge, and the maximum width keeps lines a readable length. Zooming in still works, because nothing has a fixed width below the maximum.

How to modify it

The width and padding come from --container-* variables defined in :root in ncss.css. Change a variable and every container follows, or set it on a parent element to change only the containers inside it.
