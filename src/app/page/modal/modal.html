How to use

nc-modal is a dialog on top of a dimmed page. It is built from plain elements instead of the native dialog element, with the dialog semantics added by hand. It opens and closes through [(open)], or through the methods show(), hide() and toggle(). It has no trigger of its own: use a normal button.

Accessibility

  • The modal is role="dialog" (or alertdialog) with aria-modal="true", named by its heading through aria-labelledby. Give an ariaLabel if there is no heading.
  • While it is open, the rest of the page is made inert: it cannot be reached by keyboard, mouse or screen reader, and the page does not scroll. This is what the native dialog element does, done by hand so the overlay works in any layout.
  • Focus moves inside when it opens (to data-autofocus, else the first field or button) and goes back to the button that opened it when it closes. Tab and Shift+Tab stay inside.
  • Escape closes the top-most dialog only. A click or drag that starts inside the panel never closes it, only a click that starts and ends on the backdrop.
  • Use role="alertdialog" for questions that need an answer. Its content is read automatically, and putting data-autofocus on the safest button is a good habit.
  • Animations stop with reduced motion, and Windows high contrast mode draws borders.
  • Content inside a closed modal is still created once, like any projected content, but not shown.
