How to use

nc-card-list shows a card per item, with an optional title and text, and edit and delete buttons. It never changes your data: it emits events and you update your own signal. If you want a compact, table-like list instead, use the crud list.

Accessibility

  • It is a real ul. Every button has a name that includes the card, such as "Delete, Billing".
  • With clickable the content is a button: Tab, Enter and Space work and the focus ring follows the theme.

How to modify it

Spacing and colors come from --list-* variables defined in :root in ncss.css. The cards themselves are normal cards, so the --card-* variables apply too.
