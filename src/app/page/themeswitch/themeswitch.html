How to use

The theme switch is an Angular component with the element selector nc-theme-switch. It is an icon button that opens a short list of themes, and it does its work through ThemeService. The choice is applied to the whole page and remembered between visits. Place it anywhere, usually in the top bar.

Accessibility

  • The trigger is a real button. Its name includes the current theme ("Theme: Dark") and updates when it changes, and aria-expanded says whether the list is open. The palette icon is hidden from screen readers.
  • The list is a group of native radio buttons with a hidden "Theme" legend, so screen readers announce "Theme, group, Dark, radio button, 2 of 5, selected". Arrow keys move between themes and apply them straight away, which also gives a live preview.
  • Opening the list moves focus to the current theme. Escape closes it and returns focus to the button. Clicking outside, tabbing away or choosing a theme with the mouse also closes it.
  • The selected theme is shown by a filled dot and bold text, not by color alone. Focus rings, Windows high contrast mode and the themes themselves are handled.
  • Use label and labels to translate the names.
