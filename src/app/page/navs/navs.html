How to use

The top navigation is an Angular component with the element selector nc-topnav. Give it a list of links, and optionally a logo and custom content. Links can be simple routes or dropdowns of routes. It highlights the current page and sticks to the top while the page scrolls.

Responsive behavior

The nav measures its own width, not the window. Below 768px the links are replaced by a menu button that opens a panel with all the links, dropdown items included. This is why both demos above work on the same screen. The breakpoint is fixed, and it is not meant for a long list of links.

Accessibility

  • The links sit in a nav landmark named by ariaLabel and are a real list of real links, so everything works with Tab and Enter.
  • The current page gets aria-current="page" and is also bold and underlined, so it is not shown by color alone. A dropdown is marked when one of its pages is current.
  • Dropdowns follow the disclosure pattern: a button with aria-expanded that reveals a list of links. They are not ARIA menus, because a site's links are navigation, not application commands.
  • Escape closes whatever is open and returns focus to the button that opened it. Clicking outside, tabbing out, or following a link also closes it.
  • The menu button on narrow navs has its own name (menuLabel) and aria-expanded. Icons are hidden from screen readers.
  • If the page has more than one navigation, give each a different ariaLabel. Add a "skip to content" link before the nav on real sites so keyboard users can jump past it.
  • Focus rings, Windows high contrast mode and reduced motion are handled.

How to modify it

Colors, height and shadows come from --topnav-* variables defined in :root in ncss.css, and every theme overrides them. Dropdowns reuse the select list variables. Change a variable and every nav follows, or set it on a parent element to change only the navs inside it.
