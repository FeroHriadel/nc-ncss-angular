How to use

The checkbox is an Angular component with the element selector nc-checkbox. Inside it is a real input type="checkbox" wrapped in a label, drawn with CSS. Because the native element stays in the DOM, keyboard, focus, form and screen reader support come from the browser.

Accessibility

  • It is a native checkbox, so Space toggles it, Tab moves to it, and screen readers announce its role, name and state.
  • The visible label is the accessible name, and clicking it toggles the checkbox. Use ariaLabel only when there is no visible label.
  • indeterminate is exposed as the mixed state. required and invalid are announced, and ariaDescribedby links a hint or error message.
  • The check mark is CSS only, so it is never read out. Disabled checkboxes leave the tab order.
  • Related checkboxes should sit in a fieldset with a legend.
  • The focus ring shows for keyboard focus only. Windows high contrast mode uses system colors, and reduced motion turns off the transitions.

How to modify it

Every color, size and shadow comes from a --checkbox-* variable defined in :root in ncss.css, and every theme overrides them. Change a variable and every checkbox follows, or set it on a parent element to change only the checkboxes inside it.
