How to use

The file upload is an Angular component with the element selector nc-file-upload. It looks like an input, but a real input type="file" is stretched invisibly over it. Clicking, keyboard use (Tab, then Enter or Space), dragging files onto it and form submits are all handled by the browser.

Files that are the wrong type or too big are never added to files. They are reported through the (rejected) output as {{ '{ file, reason }' }} with the reason 'type' or 'size', so you decide how to tell the user. Programmatically you can only clear the field, not add files to it.

Accessibility

  • The native file input stays in the page (only invisible), so it is focusable and announced as a file chooser. It is the one control screen readers and keyboards use.
  • Give it a name: a label with for pointing at inputId, or ariaLabel. The placeholder is only decoration.
  • Choosing, rejecting or clearing files is announced through a polite live region ("report.pdf selected", "1 file rejected", "Selection cleared").
  • The clear button only exists while there are files, is a real button with its own name, and returns focus to the field.
  • Link hints and errors with ariaDescribedby and set invalid. Do not rely on the red border alone, show the error text too.
  • The focus ring shows for keyboard focus only, and the drag-over state uses the same ring plus a dashed border. Windows high contrast mode and reduced motion are respected.

How to modify it

It uses the same --input-* variables as the input and password, defined in :root in ncss.css and overridden by every theme. Change a variable and all of them follow, or set it on a parent element to change only the ones inside it.
