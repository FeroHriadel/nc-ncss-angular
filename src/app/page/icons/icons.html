Accessibility

  • Icons are decorative by default: the inner svg has aria-hidden="true", so screen readers skip it. Next to a label there is nothing more to do.
  • An icon-only control needs a name on the control itself, such as aria-label on the button.
  • If an icon alone carries meaning (for example a status), put role="img" and an aria-label on the icon element itself.
  • Do not use color as the only signal. A red warning icon still needs text or a name.
